# Reni R. — Portfolio Website

A responsive React + Vite portfolio using a Marian-inspired palette: deep blue, white, and subtle gold accents.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

## Build for deployment
Run `npm run build`. Upload the generated `dist` folder to a static hosting provider, or connect this project to Vercel/Netlify.

## Before publishing
- Confirm every project bullet accurately reflects your contribution.
- Add a public resume PDF to `public/` and add a visible download link if desired.
- Add a professional photo only if you want one.
- Do not publish company source code, credentials, confidential screenshots, or client information without permission.
- Verify contact details and external profile URLs.

## Edit content
Main content is in `src/App.jsx`; styling is in `src/styles.css`.
